# Manor Multi-Site Migration - Client Facing Overview

A single-page, client-facing presentation of the Manor multi-site SEO migration scope.

## Contents

- `index.html` - self-contained presentation (Bootstrap 5 + Chart.js via CDN)

## What it covers

- Scale: 6 acquired sites, 1,038 source URLs, ~10 locations, ~1,448 monthly visits
- Search equity by site (Domain Rating, backlinks, organic traffic)
- URL disposition breakdown (rebuild / merge / retire / direct redirect)
- Two architecture options (location-scoped vs global services) with effort estimates
- Hours by department, with charts and tables
- Pros, cons, and a hybrid recommendation

## Notes

- Figures are directional planning estimates, not GA4 or Search Console actuals.
- Effort figures reflect a 30% reduction from the prior draft.
- Requires internet access to load Bootstrap and Chart.js from CDN.
