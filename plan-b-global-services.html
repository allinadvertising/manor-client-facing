PLAN B - Global Services Architecture (Fewer, Stronger Pages)

Destination: https://thisismanor.com/ Scope: 6 Influx CMS sites to WordPress. 1,038 source URLs, ~10 physical locations, ~50 unique service types.

Architecture (locked)

/locations/{city}/                 <- one page per physical location
/services/{service}/               <- ONE consolidated national page per service
/providers/{provider}/             <- ONE national page per unique provider
/blog/{post}/                      <- consolidated editorial
/gallery/{location}/               <- one gallery per location

No location-scoped service pages. Each service has a single strong page (/services/botox/) that absorbs content, links, and intent from all six source sites. Location pages link down to the relevant services; services link back to locations for NAP/booking.

Why this plan

Matches what is currently live on Manor today (service-sitemap.xml = 25 global /services/*, location-sitemap.xml = 5 /locations/*). Fewer, deeper pages avoid the thin-page risk the precedent itself warns about, concentrate authority (one page = one keyword cluster instead of 10 near-duplicates), and scale cleanly with future acquisitions (a new city = one location page, not a new page per service).

Sequencing

Same waves/gates as the shared methodology. Redirects carry more consolidation decisions (each of ~50 services receives 3-6 source URLs to one destination), so the redirect map needs an explicit merge-cluster review before handoff.

Key risks

  1. Loss of local SERP coverage. A consolidated /services/botox/ may not rank for "botox scottsdale" or "med spa santa fe" as strongly as a dedicated local page; local terms must be carried on the location page instead (title/meta/H1 + internal anchors).
  2. Consolidation loss. Merging 5 pages into one risks dropping unique content if the merge is not disciplined (the precedent's "preserve content blocks" rule).
  3. Diverges from the reference precedent. Management must explicitly accept departing from the location-scoped model the prior plans locked.
